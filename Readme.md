## 🧠 Why This Repo Exists

This repository is my **living notebook** — a space where I turn concepts into code.

Every project here reflects:
- 🔍 **Curious Learning** — diving deep into *why* things work, not just *how*
- 🔄 **Consistent Practice** — committing regularly, building something real every few days
- 🎯 **Core Fundamentals First** — useState, props, component architecture, controlled forms — mastered before moving on
- 💨 **Latest Tailwind Practices** — utility-first styling, responsive design, dark mode, and modern class patterns
- ⚛️ **Modern React Patterns** — hooks, lifting state, component composition, and clean JSX

---

## 📁 Projects

### 🛒 [Anime-Cart](./Anime-Cart)
> A shopping cart UI with an anime theme

An interactive cart built to master **state management** and **dynamic rendering** in React.

**Key Concepts:** `useState`, conditional rendering, list rendering, component composition  
**Styling:** Tailwind utility classes, responsive grid layout

---

### 📚 [Course-Page](./Course-Page)
> A course listing/detail page UI

A clean, structured course-browsing interface to practice **props-driven UI** and **component reuse**.

**Key Concepts:** Props, component hierarchy, data-driven rendering  
**Styling:** Tailwind card layouts, typography utilities, spacing system

---

### 🐦 [Mini-Twitter](./Mini-Twitter)
> A minimal Twitter/X-like feed UI

A social feed clone to explore **dynamic lists**, **user interactions**, and **controlled components**.

**Key Concepts:** `useState`, event handling, lifting state up, form inputs  
**Styling:** Tailwind flex layouts, hover states, responsive design

---

### 💬 [Testimonial-Slider](./Testimonial-Slider)
> An auto-playing testimonial/review carousel

A smooth slider component built to understand **timers in React**, **index-based navigation**, and **side effects**.

**Key Concepts:** `useEffect`, `useState`, `setInterval`, cleanup functions  
**Styling:** Tailwind transitions, card shadows, text alignment

---

### 📝 [react-form-handling-exercise](./react-form-handling-exercise)
> A hands-on form handling exercise with card management

A form-driven project that practices **controlled inputs**, **validation patterns**, and **remove card functionality**.

**Key Concepts:** Controlled components, `useState` for forms, array manipulation (`filter`), event-driven UI  
**Styling:** Tailwind form elements, dynamic card grid

## 📈 Progress Philosophy

```
Curious → Build → Break → Fix → Understand → Repeat
```

| Habit | Practice |
|---|---|
| 🔥 Consistent commits | Build something every few days |
| 📖 Read before writing | Understand the concept before coding it |

| 💨 Tailwind-first styling | No custom CSS unless Tailwind can't do it |

## 🚀 Getting Started

Clone and explore any mini-project:

```bash
# Clone the repo
git clone https://github.com/vighnesh204/react-ui-playground.git

# Navigate into a project
cd react-ui-playground/Anime-Cart

# Install dependencies
npm install

# Start the dev server
npm run dev
```
